# Publicación estática de cohifis.com

La carpeta `/public` contiene la **versión estática lista para publicación** de cohifis.com como hub comercial multi-producto.

## Objetivo de esta carpeta

- Servir el sitio directamente como HTML/CSS estático desde la raíz del hosting.
- Mantener la estrategia comercial aprobada:
  - Hub comercial multi-producto.
  - Producto destacado: Seguro de Vida Temporal (sin hacerlo único).
  - Rutas de WhatsApp por línea comercial.

## Rutas de WhatsApp vigentes

- SECOM Auto: `https://wa.me/5216683211342`
- Vida Temporal, IMSS, TPV, créditos empresariales y seguros empresariales: `https://wa.me/5216681855146`

## Estructura

- `index.html`
- `seguro-de-vida-temporal.html`
- `styles.css`

## Relación con `/prototype`

- `/public` es la versión preparada para publicación.
- `/prototype` se conserva como **respaldo de trabajo** y referencia histórica del prototipo aprobado.

## Uso

No requiere dependencias ni build.

1. Abrir `public/index.html` en el navegador, o
2. Servir de forma estática con cualquier hosting de archivos.
